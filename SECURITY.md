# Security

## Supported versions

Fixes go into `main` and ship in the next App Store and TestFlight build. Only the current App Store release is supported.

## Reporting a vulnerability

Report it privately through GitHub's form: [Report a vulnerability](https://github.com/inceptyon-labs/ithaca/security/advisories/new). Don't open a public issue.

Include what an attacker can do, the steps to reproduce, and the platform and Ithaca version. Leave out your Plex token and server addresses; we'll ask if they're needed.

Problems in Plex Media Server itself go to Plex. Problems in [Athena](https://github.com/inceptyon-labs/athena) go to that repository.

## What to expect

A reply within a few days, an estimate once the problem is confirmed, and credit in the release notes if you want it.
